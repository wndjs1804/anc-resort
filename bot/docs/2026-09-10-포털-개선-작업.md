# 2026-09-10 휴양시설 포털 개선 작업

## 목적

휴양시설 조회 화면을 제공된 디자인 참고 자료에 맞게 개편하고, 리조트별 객실 사진·미래 일정 조회·콘텐츠 관리·공휴일 표시를 운영 서비스에 추가했다. 예약·취소·대기신청 기능은 추가하지 않았다.

## 적용 내용

### 화면과 브랜드

- 제공된 휴양시설 참고 PNG와 디자인 토큰을 기준으로 사이드바, 히어로, 조회 조건, 달력, 일정 카드, 객실 표, 공지, FAQ를 반응형으로 개편했다.
- 좌측 상단은 `에이스나노켐(영문로고).png` 원본을 `web/public/assets/ace-nanochem-logo.png`로 복사해 사용한다.
- 히어로의 `COMPANY BENEFIT 3` 문구를 제거했다.
- 320px부터 1680px까지 가로 넘침 없이 표시되도록 검증했다.
- 최종 제공된 가로 이미지를 `resort-hero-v3.png`, 세로 이미지를 `sidebar-resort-v3.png`로 추가했다.
- 상단과 사이드바 이미지는 `cover` 크롭 대신 영역 전체에 맞춰 표시하여 야자수·바다·파라솔·선베드가 잘리지 않게 했다.
- 히어로의 흰색 오버레이는 제목이 놓이는 왼쪽에만 제한하고, Sky/Aqua/Green 색감은 원본에 가깝게 유지했다.
- 사이드바 폭·로고·메뉴, 히어로 제목, 검색·일정 카드의 간격과 시각 효과를 새 디자인 가이드에 맞췄다.
- 공지 제목은 FAQ와 같은 `16px / 600`, 공지 본문은 `14px / line-height 1.8`로 조정했다.

### 조회 경험

- 첫 진입과 숙소 선택 변경 시에는 이전·기본 숙소의 달력을 표시하지 않는다. 사용자가 `조회하기`를 누른 뒤에만 현재 선택한 숙소의 달력 결과를 표시한다.
- 첫 조회나 Cloud Run 콜드 스타트 중에 화면 중앙 로딩 모달, 스피너, 경과 시간, 안내 문구를 표시한다.
- 사용자가 리조트·숙소·동을 바꾸는 동안 이전 요청 응답이 뒤늦게 도착해도 현재 화면을 덮어쓰지 않도록 요청 ID를 검증한다.
- 미래 월로 이동할 때 Firestore 저장본이 없으면 해당 월을 자동 조회한다. 화면에 공통 미래 월 상한은 없다.
- 한화 운영 API에서 2026년 11월 30일치와 12월 31일치 응답을 확인했다.
- 아난티는 숙소별로 다른 예약 오픈 기간을 `init-calendar` 응답에서 받아 표시한다. 날짜별 잔여가 아닌 예약 오픈 여부라는 기존 의미는 유지한다.

### 객실 목록과 사진

- 객실을 종류별로 그룹화하고 스탠다드·패밀리 → 디럭스·캐빈 → 프리미어 → 스위트 → 로열·플래티넘 순으로 정렬한다.
- 같은 등급은 한국어 객실명순으로 정렬하고, 알 수 없는 새 등급명은 목록 뒤에서 이름순으로 안정적으로 표시한다.
- `가능 객실만 보기`는 `available`, `closing`만 남기고 `현재건수/전체건수`를 표시한다.
- 아난티는 공식 예약 화면의 객실 코드로 대표 사진 그룹을 연결했다. 한화는 `LOC_CD` → `ROOM_TYPE_CD` 공개 객실 안내에서 사진을 수집했다.
- 상세 조사는 `bot/docs/anantti-images/README.md`, `bot/docs/hanwha-images/README.md`를 참고한다.

### 관리자 콘텐츠

- 좌측 하단 ACE nanochem 이미지를 더블클릭하면 관리자 로그인 다이얼로그가 열린다.
- 인증 후 공지사항 등록·수정·삭제와 FAQ 추가·수정·삭제를 사용할 수 있다.
- 이미지를 다시 더블클릭하면 세션을 제거하고 즉시 로그아웃한다.
- 관리자 비밀번호는 `admin-password` Secret Manager에만 있다. 서버가 8시간 서명 세션을 발급하고, 브라우저는 `sessionStorage`에 세션만 보관한다.
- 동일 접속자의 로그인 실패는 15분에 5회로 제한한다.
- 수정분은 `portalContent/{contentId}`에 저장한다. 기본 FAQ 삭제는 `deleted: true` tombstone으로 남긴다.
- Firestore 보안 규칙은 클라이언트 쓰기를 허용하지 않고 Cloud Run Admin SDK만 쓴다.
- 공지 내용 입력칸에서 `Ctrl+V` 또는 `⌘V`로 PNG/JPG/WebP 이미지를 계속 붙여넣을 수 있다. 이미지 개수 제한은 없고 각 이미지는 4MB 이하이다.
- 붙여넣은 이미지는 각각 미리보기·개별 삭제할 수 있으며 공지 본문 아래에 등록 순서대로 표시된다.
- `첨부파일`은 파일 형식 제한 없이 여러 개 선택할 수 있고, 각 파일은 10MB 이하이다. 공지에는 다운로드 목록으로 표시된다.
- 파일은 한 개씩 `POST /admin/upload`로 전송해 단일 HTTP 요청이 과도하게 커지지 않게 했다.
- 공지를 수정·삭제하면 더 이상 참조하지 않는 Storage 객체도 제거한다. 기존 단일 이미지 공지도 새 구조와 호환한다.
- Cloud Run 서비스 계정에는 `gs://anc-resort-rooms` 버킷 범위의 `roles/storage.objectAdmin`만 추가했다.

### 대한민국 공휴일

- `date-holidays` 한국 데이터로 신정, 국경일, 석가탄신일, 기독탄신일, 대체공휴일을 가져온다.
- 패키지가 설날·추석 당일만 주는 부분은 서버에서 전날·다음 날을 `연휴`로 확장한다.
- `/holidays?year=YYYY`로 연도별 데이터를 제공하고 화면에서 해당 연도를 한 번만 요청한다.
- 모든 날짜 칸에 휴일명 한 줄 높이를 동일하게 예약하고, 객실 상태 배지를 칸 하단에 고정해 일반 날짜와 공휴일의 정렬을 맞춘다.
- 2026년 운영 API 검증: 설날 2/16~18, 추석 9/23~25, 3·1절·석가탄신일·광복절·개천절 대체공휴일 포함.

## API와 저장소 변경

| 구분 | 내용 |
|---|---|
| `GET /content` | 관리자 콘텐츠 변경분 조회 |
| `GET /holidays?year=` | 대한민국 연도별 공휴일 |
| `POST /admin/login` | 비밀번호 검증과 8시간 세션 발급 |
| `POST /admin/content` | 공지·FAQ 저장 또는 삭제 |
| `POST /admin/upload` | 관리자 이미지·첨부파일을 한 개씩 Storage에 업로드 |
| `portalContent/` | 공지·FAQ 변경분과 삭제 표시 |
| `portalContent.inlineImages[]` | 내용에 붙여넣은 이미지 URL·Storage 경로·파일명 |
| `portalContent.attachments[]` | 첨부파일 URL·경로·파일명·형식·크기 |
| `admin-password` | 관리자 비밀번호 Secret |

## 운영상 제한

- 공휴일 데이터는 패키지 업데이트 시점의 법정 휴일을 기준으로 한다. 임시공휴일이 나중에 지정되면 `date-holidays` 업데이트와 재배포가 필요할 수 있다.
- 아난티 달력의 `확인`은 잔여 확정이 아니라 예약 오픈 일정이다. 실제 객실 상태는 날짜를 눌러야 한다.
- 새로운 객실 등급 명칭이 등장하면 기본 등급 목록 뒤에 이름순으로 표시된다.
- 내용 이미지는 PNG/JPG/WebP 각 4MB 이하, 일반 첨부파일은 형식 제한 없이 각 10MB 이하이다.
