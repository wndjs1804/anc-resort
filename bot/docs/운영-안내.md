| 항목 | 값 |

| 봇 서비스 | `https://anc-resort-bot-551643700321.asia-northeast3.run.app` |
| 구글 프로젝트 | `anc-resort` |
| 지원 리조트 | **소노**(동 35) · **아난티**(숙소 6) · **한화**(숙소 13 / 위치 16) |

직원은 리조트 → (지역) → 숙소 → (동) → 박수를 고르고 **[조회]** 를 누릅니다.
달력에서 날짜를 누르면 객실별 예약 가능 여부와 회원가가 나옵니다.
**예약은 이 화면에서 되지 않습니다.** 화면에도 그렇게 안내돼 있습니다.

## 2. 잘 되는지 확인하는 법

브라우저 주소창에 이 주소를 넣으세요:

```
https://anc-resort-bot-551643700321.asia-northeast3.run.app/health
```

```json
{ "ok": true, "store": "ok",
  "sessions": { "sono": "alive", "anantti": "expired", "hanwha": "alive" },
  "loginsToday": { "sono": 3, "anantti": 1, "hanwha": 2 } }
```

- **`ok: true`** 면 서비스는 정상입니다.
- **`sessions` 가 `expired` 여도 문제가 아닙니다.** 조회할 때 알아서 다시 로그인합니다.
  이때 첫 조회만 20초쯤 걸립니다.
- **`loginsToday`** 가 리조트당 20 에 가까우면 이상 신호입니다. 담당자에게 알려 주세요.

## 3. 자주 겪는 상황

| 증상 | 원인 | 할 일 |
|---|---|---|
| 조회가 20~30초 걸림 | 한동안 안 써서 서버가 꺼져 있었음 | 정상입니다. 두 번째부터 빨라집니다 |
| "조회 중…" 에서 안 끝남 | 60초까지 기다렸다 오류를 띄웁니다 | [조회] 를 한 번 더 누르세요 |
| "지금은 확인이 안 됩니다" | 리조트 사이트 로그인 실패 | `/health` 확인 → 계속되면 비밀번호 변경 여부 확인 |
| "리조트 사이트 점검 중입니다" | 상대 사이트 점검 | 기다리면 됩니다 |
| 금액이 `—` 로만 나옴 | 그 객실이 마감 | 정상입니다 |
| 달력이 점선(확인 필요) | 처음 보는 상태 코드 | **알려 주세요.** 사이트가 바뀐 신호입니다 |

## 4. 리조트 비밀번호를 바꿨을 때

```bash
printf '새 비밀번호: '; stty -echo; read PW; stty echo; echo
printf '%s' "$PW" | gcloud secrets versions add sono-pw --data-file=- --project=anc-resort
unset PW
```

`sono-pw` 자리에 바꿀 것을 넣으세요:
`sono-id` · `sono-pw` · `anantti-id` · `anantti-pw` · `hanwha-id` · `hanwha-pw` · `hanwha-member-pw`

그 다음 봇을 새 값으로 다시 띄웁니다:

```bash
cd /Users/song/Desktop/ace-resort && bash 배포.sh
```

## 5. 화면 주소(토큰)가 유출된 것 같을 때

```bash
cd /Users/song/Desktop/ace-resort
printf '%s' "$(node -e 'process.stdout.write(require("crypto").randomBytes(24).toString("base64url"))')" \
  | gcloud secrets versions add board-token --data-file=- --project=anc-resort
bash 배포.sh
node -e "console.log('새 주소: https://anc-resort.web.app/?t=' + process.argv[1])" \
  "$(gcloud secrets versions access latest --secret=board-token --project=anc-resort)"
```

마지막에 나오는 새 주소를 포털 위젯 설정의 `Iframe URL` 에 넣으면 옛 주소는 막힙니다.

## 6. 비용

- 결제 계정: `ace-resort` · **예산 알림 월 5만원**(50/90/100% 에서 메일)
- Cloud Run 을 꺼지게 두는 설정(`min-instances=0`)이라 **평소 비용은 거의 없습니다.**
- 항상 빠르게 하려면 `min-instances=1` 로 올리면 되지만 **월 2~3만원**이 듭니다.

## 7. 조심할 것

- **이 도구는 읽기만 합니다.** 예약·취소·대기신청을 하지 않습니다.
- 리조트 계정은 Secret Manager 에만 있습니다. 코드·파일 어디에도 적지 마세요.
- `bot/docs/captures/` 에는 사이트 응답 원문이 들어 있습니다. **외부로 보내지 마세요.**
- 화면 주소의 `t=...` 는 접근 토큰입니다. 사외 공유 금지입니다.

## 8. 리조트 사이트가 바뀌면

증상은 대개 이렇게 나타납니다.

| 증상 | 봐야 할 곳 |
|---|---|
| 달력이 점선(확인 필요) | 상태 코드 표 — `docs/<리조트>-site-notes.md` |
| "지금은 확인이 안 됩니다" 가 계속됨 | 로그인 화면 구조가 바뀐 것 |
| 금액만 안 나옴 | 요금 API 파라미터가 바뀐 것 |

고칠 곳은 어댑터 파일 **맨 위 상수 블록**에 모여 있습니다:
`bot/src/adapters/sono.ts` · `anantti.ts` · `hanwha.ts`

사이트 구조를 다시 확인하려면:

```bash
cd /Users/song/Desktop/ace-resort/bot
npm run explore:sono -- --login      # 아난티는 explore:anantti, 한화는 explore:hanwha
```

브라우저가 뜨면 직접 눌러 가며 진행하고, 끝나면 터미널에 `q` + Enter.
기록이 `docs/captures/` 에 남습니다.
