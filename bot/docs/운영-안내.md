# ANC 휴양시설 이용조회 — 운영 안내

> 담당자용 문서입니다. 계정·비밀번호·토큰 값은 문서에 적지 않습니다.

## 1. 현재 서비스

| 항목 | 값 |
|---|---|
| 직원 화면 | `https://anc-resort.web.app` |
| 봇 서비스 | `https://anc-resort-bot-551643700321.asia-northeast3.run.app` |
| Google Cloud 프로젝트 | `anc-resort` |
| 지원 리조트 | 소노·아난티·한화 |

직원은 리조트 → 지역/숙소/동 → 박수를 고르고 `조회하기`를 누릅니다. 처음 들어오거나 숙소를 바꾼 직후에는 달력이 표시되지 않으며, 조회를 누른 뒤 선택한 숙소의 달력이 나타납니다. 날짜를 누르면 객실별 예약 상태와 회원가가 나옵니다. 이 화면에서 예약·취소·대기신청은 할 수 없습니다.

- 미래 월로 이동했을 때 저장본이 없으면 실제 리조트 사이트를 자동 조회합니다.
- 아난티의 숙소별 6주·8주 등 오픈 기간은 실제 사이트 응답을 그대로 따릅니다.
- 달력에 대한민국 공휴일, 설날·추석 연휴, 대체공휴일을 표시합니다.
- 객실은 종류별·낮은 등급순으로 정렬됩니다. `가능 객실만 보기`는 예약가능과 잔여객실 적음만 남깁니다.

## 2. 정상 작동 확인

브라우저에서 아래 주소를 엽니다.

```
https://anc-resort-bot-551643700321.asia-northeast3.run.app/health
```

- `ok: true`: 서비스와 Firestore 정상
- `sessions` 값이 `expired`: 장애가 아님. 다음 조회에서 자동 로그인
- `loginsToday`가 리조트당 20회에 가까우면 반복 로그인 원인 확인

## 3. 공지사항과 FAQ 관리

1. PC 화면 좌측 하단 ACE nanochem 이미지를 더블클릭합니다.
2. 관리자 비밀번호를 입력합니다.
3. 공지사항에서 `등록하기`, `수정`, `삭제`를 사용합니다.
4. FAQ에서 `질문 추가`, `수정`, `삭제`를 사용합니다.
5. 관리를 끝내려면 좌측 하단 이미지를 다시 더블클릭합니다.

공지에 이미지와 파일을 넣는 방법:

- 캡처 이미지는 `내용` 입력칸을 클릭한 뒤 `Ctrl+V`(Mac은 `⌘V`)로 붙여넣습니다. 계속 붙여넣으면 여러 장이 순서대로 추가됩니다.
- 붙여넣기 이미지는 PNG/JPG/WebP, 이미지별 최대 4MB입니다. 개수 제한은 없습니다.
- 문서·압축파일 등은 `첨부파일`에서 선택합니다. 모든 파일 형식을 지원하고 여러 개를 선택할 수 있으며 파일별 최대 10MB입니다.
- 저장 전에 이미지와 첨부파일을 각각 개별 삭제할 수 있습니다.
- 저장된 공지를 펼치면 본문 이미지와 첨부파일 다운로드 목록이 함께 표시됩니다.

관리자 세션은 현재 브라우저 탭에만 저장되며 8시간 후 만료됩니다. 동일 접속자가 15분 동안 5회 실패하면 추가 로그인이 잠시 제한됩니다.

## 4. 비밀번호 변경

관리자 비밀번호:

```bash
printf '새 관리자 비밀번호: '; stty -echo; read ADMIN_PW; stty echo; echo
printf '%s' "$ADMIN_PW" | gcloud secrets versions add admin-password --data-file=- --project=anc-resort
unset ADMIN_PW
cd /Users/song/Desktop/ace-resort && bash 배포.sh bot
```

리조트 비밀번호:

```bash
printf '새 비밀번호: '; stty -echo; read RESORT_PW; stty echo; echo
printf '%s' "$RESORT_PW" | gcloud secrets versions add sono-pw --data-file=- --project=anc-resort
unset RESORT_PW
cd /Users/song/Desktop/ace-resort && bash 배포.sh bot
```

`sono-pw` 자리에 `anantti-pw`, `hanwha-pw`, `hanwha-member-pw` 등 변경 대상 Secret 이름을 넣습니다.

## 5. 자주 겪는 상황

| 증상 | 원인 | 할 일 |
|---|---|---|
| 첫 조회가 20~30초 | Cloud Run 콜드 스타트 | 정상. 두 번째부터 빨라짐 |
| 조회가 끝나지 않음 | 60초 타임아웃 대기 | 안내가 사라진 뒤 다시 조회 |
| `지금은 확인이 안 됩니다` | 로그인 또는 파싱 실패 | `/health` 확인 후 비밀번호·사이트 변경 점검 |
| 달력이 점선 | 처음 보는 상태 코드 | 개발 담당자에게 알림 |
| 관리 버튼이 안 보임 | 관리자 모드가 아님 | 좌측 하단 이미지 더블클릭 |

## 7. 보안과 비용

- 리조트 계정, 화면 토큰, 관리자 비밀번호는 Secret Manager에만 보관합니다.
- Firestore 클라이언트 쓰기는 모두 금지되며, 콘텐츠는 관리자 세션을 검증한 Cloud Run만 저장합니다.
- 공지 이미지와 첨부파일은 `gs://anc-resort-rooms/portal/notices/`에 저장되며 Cloud Run 서비스 계정만 객체를 관리합니다.
- Cloud Run `min-instances=0`이므로 평소 비용은 적지만 첫 조회가 느릴 수 있습니다.
- 화면 주소의 `t=...`는 사외에 공유하지 않습니다.
