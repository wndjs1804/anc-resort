# ACE nanochem 휴양시설 이용조회 — 디자인 가이드

> 목적: 기존 **휴양시설 이용조회 페이지의 기능·정보 구조는 유지**하면서,
> ACE nanochem의 기업 이미지를 살리고 휴양시설 서비스 특유의 **밝고 여유로운 휴식감**을 강화한다.
> 디자인 방향은 **Clean Corporate + Modern Resort Illustration**이다.

---

## 1. 핵심 디자인 방향

### 유지할 것
- 좌측 사이드바 구조
- 상단 휴양시설 비주얼 영역
- 검색 조건 영역
- `선택한 일정` 정보 카드
- 하단 안내 문구 및 Footer
- 기존 메뉴명과 조회 흐름
- 현재 제공 중인 데이터/기능

### 변경할 것
- 상단 제목 및 안내 문구 크기 축소
- 회사 로고 크기 축소 및 여백 재조정
- 상단 사진형 이미지를 **감각적인 휴양지 일러스트**로 변경
- 좌측 하단 이미지도 상단과 통일된 일러스트 스타일로 변경
- 좌측 이미지의 카피/문구를 더 세련된 휴식 메시지로 변경
- 전체 카드, 버튼, 입력창, 여백, 그림자 톤을 현대적으로 정리
- 전체 색상은 ACE Blue를 중심으로 하되, 휴양지 느낌의 Sky / Aqua / Sand 컬러를 보조 사용

---

# 2. 디자인 키워드

`Clean` / `Airy` / `Resort` / `Corporate` / `Illustration` / `Fresh` / `Blue` / `Relaxed`

디자인에서 가장 중요한 인상은 다음 순서이다.

1. 휴양시설 서비스라는 느낌
2. ACE nanochem 사내 시스템이라는 신뢰감
3. 복잡하지 않고 편안한 UI
4. 시원한 바다·여행 이미지를 통한 감성
5. 실제 업무 시스템으로 사용 가능한 높은 가독성

# 23. 이미지 사용 시 주의사항

- 이미지에 AI가 임의로 한글 또는 영문을 생성하지 않도록 한다.
- 카피는 HTML/CSS text로 별도 구현하는 것을 우선한다.
- Hero는 텍스트가 들어갈 공간을 반드시 확보한다.
- 휴양지 이미지가 과도하게 광고 배너처럼 보이지 않도록 한다.
- ACE nanochem의 Blue identity와 충돌하는 Pink / Purple 중심 팔레트는 사용하지 않는다.
- 유아용 캐릭터 스타일, 과도한 cartoon style은 사용하지 않는다.
- 실제 Resort 브랜드 Logo는 이미지에 삽입하지 않는다.

# 26. 개발 AI에게 전달할 핵심 명령

```text
첨부한 휴양시설 이용조회 디자인 레퍼런스와 이 DESIGN.md를 기준으로
현재 페이지 UI를 수정해줘.

중요:
1. 기존 기능과 데이터 로직은 절대 변경하지 않는다.
2. 기존 메뉴 및 정보구조도 유지한다.
3. 디자인만 변경한다.
4. 상단 Hero는 실사사진이 아닌 휴양지 flat vector illustration을 사용한다.
5. 좌측 하단도 같은 스타일의 vertical illustration을 사용한다.
6. ACE nanochem 로고는 현재보다 작게 표시한다.
7. Hero의 '휴양시설 이용조회' 제목 역시 현재보다 작게 표시한다.
8. 전체 레이아웃은 넓고 여유롭게, 카드 중심의 clean corporate UI로 만든다.
9. ACE Blue를 Primary로 유지하면서 Sky/Aqua/Sand 계열을 보조색으로 사용한다.
10. 과도한 그림자, gradient, glassmorphism, 둥근 모서리는 피한다.
11. Search Card는 Hero 하단과 살짝 겹치는 floating card 형태로 구현한다.
12. 화면의 핵심은 '회사 시스템'이 아니라 '편리하게 휴양시설을 조회하는 경험'으로 보이게 한다.
```
